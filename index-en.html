🏗️ The problem the x-ray solves

Agents grow in silence: nobody measures quality, cost or effect. Prisma gives visibility before the damage becomes a habit.
27kagents in the operation
2%move the needle
0quality visibility

🧾 Decision 1 · Vanilla SPA, zero backend

A single HTML file with pure CSS and JS — no build, server or dependency. The prototype runs anywhere and the evaluation logic stays transparent, auditable line by line.

🧾 Decision 2 · Everything derives from the sources

No number is guessed: every score is a calculation over the agent catalog or production interactions. If a datum does not exist, the criterion drops — never invent.

🧾 Decision 3 · LLM-as-judge in the eval pillar

Relevancy, faithfulness, planning and efficiency follow the DeepEval/RAGAS standards the eval pipeline already emits — the prototype uses record proxies; in production, it consumes the real scores.

🧾 Decision 4 · Evolution by snapshot

Every prompt change generates a new snapshot of the agent: before × after, weekly trend and gates. The improvement loop becomes routine, not a project.
